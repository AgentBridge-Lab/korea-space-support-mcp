# 우주·항공 지원사업 공고 최신화 보고서

## 요약

- 공식 공개 출처 17개 경로를 확인했고 수집 오류는 없었습니다.
- 공고 56건을 생성했습니다. 국내 31건, NASA 국제참여 25건입니다.
- 활성 공고는 16건, 마감 공고는 40건이며 제외 레코드는 없습니다.
- 직전 스냅샷과 비교해 2건이 추가되고 4건이 목록에서 빠졌습니다. 마감일 변경 1건과 상태 변경 5건도 반영했습니다.

   - 신청 마감: 2026-11-09
   - 원문: https://www.krit.re.kr/krit/bbs/notice_view.do?bbsId=notice&nttId=6561&menu_no=05010000

## 변경 사항

- 우주항공청 2건, 국방기술진흥연구소 이전 공모 1건, 경남테크노파크 1건은 최신 수집 범위에서 빠졌습니다. 재공고 대체 또는 최신 목록 범위 이동에 따른 변경이며 삭제 이력은 `data/space-refresh-diff.json`에 보존했습니다.
- NASA NIAC 2027 Phase I 마감 시각을 공식 근거에 맞춰 `2026-10-28 23:59:59 EDT`로 바로잡았습니다.
- 국내 4건과 NASA NIAC 1건은 기준일 경과에 따라 마감 상태로 전환됐습니다. KRIT 이전 공모는 최신 재공고로 대체됐으며 제거 이력에 보존했습니다.

## 운영 점검

- 주간 자동수집이 의존성 누락 상태에서 ingest 뒤 검증에 실패하던 원인을 확인했습니다.
- 이제 필수 Node 패키지가 없으면 데이터 파일을 수정하기 전에 중단하고 `npm ci` 안내를 출력합니다.
- launchd 작업 경로를 현재 운영 체크아웃으로 옮기고 Python 실행 경로를 `/usr/bin/python3`로 고정했습니다.
- 전체 검증과 운영 배포 결과는 커밋 시점의 GitHub Actions 및 운영 API에서 최종 확인합니다.
